# 🏠 Apt-Apt — Interactive Apartment Quality Visualization Dashboard

[![Angular](https://img.shields.io/badge/Frontend-Angular-red)](https://angular.io/)
[![D3.js](https://img.shields.io/badge/Visualization-D3.js-orange)](https://d3js.org/)

**Apt-Apt** is an interactive apartment quality visualization dashboard built with Angular and D3.js. It allows users to compare apartment units based on diverse metrics like sunlight, noise levels, and view quality, utilizing a lightweight CSV-based backend.

---

## ✨ Key Features

| Pillar | Description |
|--------|-------------|
| 📊 **Interactive D3 Charts** | Dynamic visualizations of apartment metrics and comparisons |
| 🏙️ **Quality Ranking System** | Pre-calculated scores for sunlight, noise, and view quality |
| 🔄 **CSV-Based Backend** | Fast and portable data serving without the need for a full SQL server |
| 🏘️ **Comparative Analysis** | Instant "Best/Worst" unit comparisons within building developments |

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Frontend** | Angular 17, D3.js |
| **Backend** | Node.js, Express, CSV Parser |
| **Data** | Structured CSV Files |
